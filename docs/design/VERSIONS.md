# Hearthrise design versions

Newest first. Each version names its base and the changes from it. From v4.3 on, `/design-version` writes the entry and checks it against a diff of the board sources. Entries before v4.3 were pieced together from session history after the fact: they list what was asked for, not a checked diff.

## v4.2 — https://claude.ai/artifact/Pp9srMzpYmmy7H5Gs8zXsb
Base: v4.1 · 2026-10-19 · implemented on `theme-biomes` (see `V42_CHECKLIST.md`)
- Home groups today's tasks by boss and chapter, with compact rows.
- Quick add, and a default boss "The Day" whose health follows today's tasks.
- Plain action rows (no glass buttons) in the task actions, boss actions and boss edit sheets.
- Strike animation on the Home row: charge fill, hit flash, shatter, and the struck row holds its slot.
- Filter chip row inset 20 px.

## v4.1 — https://claude.ai/artifact/5bU9fETFefqgD6a1UAeZfM

- New boards: boss edit, commit/extend, Today, onboarding, away summary. Other screens are re-skinned from v4.1 parts with no board of their own.
